# ADAS 镜头设计思路（design-thinking）

> 本文件是**方法论**，回答"为什么这么做、遇到问题往哪想"，而不是"怎么操作"（操作见 SKILL.md）。
> 光学设计真正的价值在于**思路**——操作步骤会过时，思路可以复利沉淀。

---

## 0. 一句话总纲

**光学设计 = 结构选型 → 起步求解 → 分阶段释放自由度 → 像差平衡 → 物理合理性验收。**
先搭能追迹的骨架，再逐步"长出"性能；优化器是"分配"像差的工具，不是"创造"结构的工具。

---

## 1. 结构选型思路（出发点决定上限）

拿到规格（f′、F/#、视场、波段、像面尺寸），第一步不是打开 Zemax，而是判断**该用哪类结构**。

| 规格特征 | 典型结构 | 判断依据 |
|---------|---------|---------|
| 大孔径(F/2~3) + 中等视场(2ω≈30°~60°) | **双高斯** | 对称结构天然消彗差/畸变，F/# 小靠孔径 |
| 大视场(2ω>60°~100°) + 需长后焦 | **反远摄**(retrofocus) | 前组负光焦度拉开后焦距 |
| 长焦 + 小视场(2ω<10°) | **远摄/望远** | 前后组分离压缩总长 |
| 鱼眼(2ω>140°) | **鱼眼** | 大桶形畸变换取视场覆盖 |
| 变焦 | 多组变倍 + MCE | 需多重结构 |

**思路要点**：选型错了，后面再优化也救不回来。选型依据是**视场 + F/# 的组合**，不是单一指标。

---

## 2. 起步求解思路（从无到有）

**核心矛盾**：光学系统是高维非线性问题，优化器需要"够近"的初始点才能收敛到合理解，否则发散到物理不可能的结构（负厚度、极端曲率）。

**"平面起步法"的本质**（本次实战）：
1. 拿一组**成熟范例**，保留其厚度 + 玻璃（这些是物理合理的约束）
2. 把所有折射面"退化"成平面 → 得到一个**无像差校正、但能追迹**的骨架
3. 让**单个面**承担全部光焦度（用 R = -(n-1)f′ 解析求出）→ 得到**满足焦距的初始解**
4. 逐步释放其余面为变量 → 让优化器把光焦度/像差**重新分配**到全系统

**思路要点**：起步 = "退化到可解" + "逐步还原"。永远先保证"能追迹 + 焦距对"，再谈像差。

---

## 3. 优化思路（怎么一步步逼近）

**分阶段释放自由度**（这是避免发散的关键）：
- 第 1 轮：只放曲率（半径），厚度全固定 → 先定光焦度分配
- 第 2 轮：再放气隙/后焦等厚度 → 精调
- **绝不一上来全放开**，否则优化器会跑飞到负厚度

**评价函数正确姿势**（本次核心收获）：
- 先 `add_operand` 加**专项约束**（EFFL 锁焦距、AXCL/LACL 锁色差）
- 再用优化向导（点列图 Spot Radius）生成**基准采样**——它自动做"全孔径×多视场×多波长"密集追迹
- 顺序：约束在前、向导在后，用 `after_current_block` 追加不覆盖
- **手工操作数是"补充约束"，向导是"主力压像差"**，角色不能颠倒

**评价函数类型选择**：
- 接近衍射极限（显微、小像差）→ 波前 Wavefront
- 中等像差（相机、双高斯）→ 点列图 Spot Radius
- 无焦（扩束）→ 角向

## 4. 收敛判断与发散诊断思路

**收敛 ≠ 好**，要过两道关：

**第一道：MF 是否稳定？**
- DLS 相邻两轮差 < 0.001，再用 OD（正交下降）换算法确认

**第二道：物理是否合理？（更重要）**
- 焦距 EFFL 是否达标（`get_first_order_data`）
- 所有厚度 > 0？气隙 > 2mm？后焦 > 10mm？
- 厚径比（厚度 / 2×半口径）是否合理（玻璃中心厚 ≤ 口径 30~35%）？
- 边厚是否为正（胶合面尤其要查）

**发散诊断决策树**：
```
MF 高/不降 → 变量太多？缺约束？初始结构不对？
厚度跑飞 → 分阶段放变量，别一次全开
焦距跑飞 → 缺 EFFL 约束（或 solve）
色差压不下 → 玻璃配对不对（冕/火石不匹配）
```

## 5. 像差平衡思路（光学本质）

三类像差，各用各的手段：

| 像差 | 平衡手段 |
|------|---------|
| **色差**（轴向 AXCL / 倍率 LACL） | **玻璃配对**：冕牌(低色散,如K系)+火石(高色散,如F系)胶合；F-C 目标归零 |
| **球差** | **弯曲**单透镜、或用非球面；光焦度分配到多个面 |
| **场曲/像散**（大视场主矛盾） | **光焦度分布**：正负透镜组合、光阑位置 |
| **彗差/畸变** | **对称结构**（双高斯对称天生消彗差、畸变）；光阑居中 |

**思路要点**：先消色差（选玻璃），再消单色像差（调曲率/厚度）；色差是"选材料"问题，单色像差是"调形状"问题。

## 6. ADAS 特殊设计思路（区别于普通相机）

双高斯只是训练起点，ADAS 车载镜头的核心差异：

1. **大视场** → 反远摄/鱼眼结构，而非双高斯；视场常以**像高**定义（配传感器）
2. **无热化**（-40~85°C）→ 多玻璃组合消温漂，需 **MCE 多温度配置**（zosmcp 当前缺此工具，见下）
3. **高相对照度** → 光阑位置、像方远心度设计，避免边缘照度骤降（用 `get_relative_illumination_data` 验收）
4. **小尺寸/耐振动** → 紧凑结构、厚径比从严

**待补能力缺口**：MCE（多重结构）、Solve（面求解）、公差分析——这些当前 zosmcp 没有，是无热化/量产设计的瓶颈，需后续补齐工具。

## 7. 复利原则（怎么让思路越滚越厚）

- 每完成一个设计任务，把**这次用到的思路 + 为什么**追加进本文件
- 记录"**什么结构 + 什么规格 + 什么手段 → 什么结果**"的因果链
- 失败尝试同样有价值：记录"**什么思路不 work + 为什么**"
- 宁可记"推断 + 依据"，不要只记"结论"
