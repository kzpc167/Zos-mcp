### 1.2 架构

结构形式为**双高斯演化**，**6 个元件 / 7 片玻璃**，其中 S6–S8 为胶合双胶合（L3+L4）。光阑居中置于第 4、5 片之间，整体近对称。首片前表面（S1）与末片前表面（S13）为偶次非球面，承担主要像差校正。

> **产品定位**：2ω 34.85°（水平 30.2°），F/1.4，属车载**长焦前摄**（前视 ADAS）档位；与 120°~190° 的环视广角镜头不是同一类产品，两者的像质评价口径不可直接比照。「双高斯」指的是**光学结构形式**，不是产品类别。

### 2.4 唯一未达标项的处理结论

**全视场 MTF@120 = 0.447 < 0.5**，根因是 **Petzval 场曲**：7 片玻璃的 Σ(φ/n) 已无重配空间。前序已用 MTFT/MTFS 约束、RMS 波前优化、Hammer 全局搜索（20 min）逐一验证无效，判为结构固有弱项并**接受**。

> 若客户坚持 0.5：加第 8 片弱负平场镜（放在 L6 前）或把 TOTR 放宽到 31~32 mm 重新平衡。这是结构改动，需重新走完整流程。

### 3.6 胶合组放宽到 Q4 的对比与决策

| | 定稿 ±0.01875 | 放宽 ±0.025（Q4） | 变化 |
|---|---:|---:|---|
| 胶合组 TTHI 劣化（MTF） | −0.084 | −0.101 | +20 % |
| 良率均值 | 0.481 | 0.464 | −0.017 |
| σ | 0.055 | 0.060 | +9 % |
| P10 | 0.409 | 0.382 | −0.027 |
| **良率（MTF > 0.35）** | **99.0 %** | **96.2 %** | **−2.8 pp** |
| 95 % CI 下界 | 97.7 %（稳过 95 %） | **94.1 %（贴破 95 %）** | — |

**决策：定稿保留 ±0.01875，不放大到 Q4。**

理由：良率均值虽仍高于 95 % 的常规量产门槛，但 **96.2 % 的 95 % 置信下界只有 94.1 %**，即"真值低于 95 %"尚不能被排除；而收紧到 ±0.01875 后下界为 97.7 %，可对客户明确承诺 ≥ 97 %。双胶合单片的 ±0.019 与 ±0.025 在加工上同属一档（都要上定心磨边与厚度分选），成本差远小于 2.8 pp 的报废代价。

> 若后续要降本，正确顺序是：① 折射率改按**熔炼批**抽样（当前按片独立，偏保守，预计 +3~5 pp）；② 不规则度从 0.5 光圈放宽到 1 光圈（仅贡献 0.18 µm）；③ 最后才动胶合组厚度。

## 四、杂散光与鬼影分析结论

### 4.1 总体判断

按一阶近轴模型（面组合枚举 + 双次反射，91 组）计算，**本系统不存在"锐利鬼影"**：弥散 ≤ 2 像素（4.2 µm）的组合为 **0 个**，最小弥散 571 µm，是 2 像素的 136 倍。因此**终止深度三维杂散光追迹**，不再投入算力。

### 4.2 首要管控面：面 10–11（L5 后 ↔ L6 前）

| 项 | 数值 |
|---|---|
| 出现视场 | 3.6° |
| 空气间隔 | 1.756 mm |
| 鬼影离焦（相对像面） | +1.04 mm |
| 弥散直径 | **571 µm** |
| 光线通过率 | 1.00（100 %，无遮挡） |
| 相对强度（单面 R = 0.5 %） | 1.01e−09 |
| 相对强度（单面 R = 1.0 %） | 4.05e−09 |
| 太阳照射下折算（R = 0.5 % / 1.0 %） | **1.0e−04 / 4.1e−04**（GISET 可见阈值 1e−04） |

**成因**：这 1.76 mm 的间隙等效于一个 f ≈ 4 mm 的会聚腔，入瞳 NA 0.357 直接灌入，离焦 1 mm 即摊开 `2×NA×Δz ≈ 0.5 mm`——与算出的 571 µm 自洽。**结论是结构决定的，不是优化能改的**。

次危险项：面 13–14（L7 内双面），视场 8.3°，离焦 −1.75 mm，弥散 1246 µm，强度 2.12e−10。

### 4.3 镀膜要求（强制）

- **单面 AR 残余反射率 ≤ 0.5 %**。若按 1.0 % 设计，最强鬼影折算到太阳为 4.1e−04，**超可见阈值 4 倍**，白天逆光会看到可辨光晕。
- 0.5 % 档下最坏项为 1.0e−04，**正好压在阈值线上，零余量**——因此该数值是硬下限，不是建议值。
- 需注意 AR 膜在 30°~45° 入射时残余反射会升到 1~3 %，**大视场鬼影可能比上表更亮**，这是本估算最大的不确定项；建议要求供应商提供 0°~45° 的反射率曲线，并对 Φ 最大的 S1、S13 重点控制。

### 4.4 结构措施（交结构工程师）

1. **在面 10–11 之间的 1.76 mm 间隙加消光隔圈**（内径按该处通光 + 0.2 mm，端面做消光处理，如黑色阳极氧化或消光漆），截断 L5 后表面反射光的回返路径。
2. 光阑两侧净空仅 0.406 / 0.332 mm，隔圈设计需与光阑座一体考虑，避免干涉。
3. L5 与 L6 之间是全场最敏感杂光路径，装配时该隔圈的同轴度应作为关键尺寸管控。

### 4.5 未做的部分

- **未做**三维非序列杂散光（镜筒内壁漫反射、压圈散射）：需要完整机械 CAD + BSDF 数据，属结构定型后的工作。
- **未做**三次及以上反射：量级比双次低两个数量级，且无锐利成像路径。
- 实际最大风险是**镀膜局部失效**（边缘、胶合面爬胶），一阶模型覆盖不到，需在样机阶段用强光源实测。
