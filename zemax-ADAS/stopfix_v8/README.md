## 无热化（−40 ~ +125 ℃，铝镜筒 23.6 ppm/K）

| 项 | 结果 | 判定 |
|---|---|---|
| 不调焦离焦跨度 | −25.2（−40 ℃）~ **+38.7 µm**（125 ℃） | 焦深 ±2.3 µm → 不调焦必然糊 |
| **调焦所需 sensor 位移** | **+18.6 µm（−40 ℃，后移）~ −27.8 µm（+125 ℃，前移），跨度 46.4 µm** | 建议 VCM 净行程 ±30 µm |
| 调焦后边缘 MTF@120 | 0.483（−40 ℃）~ 0.541（25 ℃） | 相对常温跌幅 **10.7 % ≤ 20 %** ✅ |
| 调焦后点列 RMS max | 3.63 ~ 3.72 µm | 与常温同量级 ✅ |
| 全温畸变 / 照度 / CRA | 0.398~0.425 % / 0.832~0.836 / 12.86~12.93° | 全温达标 ✅ |

**结论**：光学被动无热化不可行（6 片玻璃 dn/dT 同号），采用**主动调焦**，行程 46.4 µm 即可
把全温像质拉回常温水平。

**刻度换算（必读）**：公差向导按「XY 对称」模板自建 9 个视场（0/±0.7R/±1.0R 沿 X、Y 各一条，
R = 17.427°），其中 ±17.43° 轴上 4 个视场的像高 4.72 mm 已出净口径（4.668 mm），MTF 恒为 0。
所以工具打印的 `名义 0.35341` 是「9 视场取平均」= 5/9 ×（5 个有效视场平均）。
本目录 CSV 两列都给：`mtf_avg_120lpmm`（原始刻度）、`mtf_avg_corrected`（×9/5）。
折算只改刻度，劣化百分比、灵敏度排序、「名义 −x %」口径的良率都不变。

**口径提醒**：本节是**全视场平均**口径，与 §3 的"最差视场 MTF@120 = 0.5109"不是同一把尺子。
角视场余量只有 2.2 %，而平均值在公差下平均掉 6.3 %，**"角视场 > 0.5"在量产下大概率守不住**（报告 P1）；
客户若按最差视场验收，需单独用角视场口径跑，本工具链的 `DiffMTFSag` 仍是对视场求平均、不能替代。

## 采样口径

- MTF 验收一律用**原生 FFT MTF**（`analysis/fft_mtf.txt`），不用 MFE 里的 MTFT/MTFS。
- RMS 只认**原生 Standard Spot**（`analysis/standard_spot.txt`）；`get_image_quality`/RSCE
  采样稀疏，历史上对同一状态少报约 3 倍。
- "FFT MTF vs Field" 在最边缘采样点会读到 0，那是分析窗边界采样问题，不是设计缺陷。
