## 四、变量与评价函数（当前状态，直接沿用）

**变量（共 17 个）：**
- 10 个折射面半径（面 1/2/3/4/5/7/8/9/10/11）
- 离焦量（面 11 厚度）
- 6 块玻璃（替代玻璃 Substitute）

**透镜厚度已全部锁死**（面 4/7/8 厚度非变量）——这是上一轮为避免 Hammer 把厚度推到上限
（曾出现元件③ 涨成 23mm 玻璃砖、TOTR 撑到 91mm）而做的收窄。

**评价函数（192 行）：**
- 默认向导（RMS 光斑、质心参考）生成 117 条 TRAC + 11×6 类厚度边界（MNCA/MXCA/MNEA/MNCG/MXCG/MNEG）
- + 1 条 EFFL=50（保证焦距、维持 F/2）

## 六、可加工性（当前 warn，未解决）

`check_manufacturability` 报整体 **warn**：

| 元件 | 弯曲因子 B | 判定 |
|------|-----------|------|
| ①（面1/2）| 4.17 | pass |
| ②（面3/4/5）| **−5.41** | warn，极端弯月 |
| ③（面7/8/9）| **+8.01** | warn，极端弯月 |
| ④（面10/11）| −0.33 | pass |

边厚全部健康（3.16~8.33mm），问题只在**两个胶合组弯曲过大**（弯曲因子 ±5~8）。
根因：变量集不含透镜厚度，且未加形状约束，Hammer 只靠曲率+玻璃压弥散圆。

## 九、跨平台使用 MCP 的前提（重要）

要在别的平台接着用，需要满足：

1. **MCP 连接**：平台需配置 `zemax-opticstudio` MCP 服务器（stdio，指向
   `D:\Zemax-mcp\.venv\Scripts\python.exe` + `D:\Zemax-mcp\mcp_server.py --zemax-mode extension --instance 0`）。
   三入口配置参考：`Zos-mcp\.vscode\mcp.json`（VS Code）/ `claude_desktop_config_example.json`（Claude）。
2. **OpticStudio 前置**：OpticStudio 运行中 + 点 `Programming → Interactive Extension`。
3. **铁律**：zemax MCP 工具**必须严格串行**调用，绝不并行（并行会崩 MCP 进程）。
4. **优化前自检**：`get_merit_breakdown`（看厚度偏置）→ `check_manufacturability`（看 ET 与 SD/|R|）→ 才优化。
