Project Overview

Zemax MCP 工具链

用自然语言驱动 OpticStudio 做光学设计。把 ZOS-API 的操作封成 53 个 MCP 工具，任何支持 MCP 的客户端都能直接调。

53 个工具 ZOS-API / COM Python 3.13 OpticStudio 2024 R1

1它是怎么工作的

服务器不启动 Zemax，只连接到「已经在运行的」OpticStudio 实例。所以改完镜头，屏幕上的界面会同步变化。

Agent 客户端WorkBuddy / VS Code Copilot / Claude Desktop
↓ stdio

↓
tools.py镜头编辑 / 优化 / 像质分析 / 导出的具体实现
↓
OpticStudio经 ZOS-API (COM) 读写当前打开的镜头

2两种连接模式

模式行为
extension连已打开的 Zemax，需先点 Programming → Interactive Extension。边看界面边改，推荐。
standalonePython 自己拉起一个隐形实例，不需要 GUI，但每次多花 15–20 秒。

3怎么接上

  1. 建 venv、装依赖：pip install -r requirements.txt（走阿里云镜像）
  2. 复制 .env.example → .env，设 ZEMAX_MODE=extension
  3. 在客户端注册 MCP：命令填 .venv/Scripts/python.exe，参数填 mcp_server.py --zemax-mode extension --instance 0
  4. 打开 OpticStudio，点 Programming → Interactive Extension
  5. 开始对话：「读一下当前系统」「把第 3 面曲率改成 18.1」
# 手动起服务器（一般由客户端自动拉起）
python mcp_server.py --zemax-mode extension --instance 0

6踩过的坑

1
写完立刻读回是陈旧值看起来像没生效，其实已经改了。要验证就新建连接读。
2
mcp 包必须锁 1.x项目用 @server.list_tools()，2.x 已移除该 API，requirements 里写死 <2。
3
LDE 结构性操作有 COM 时序问题InsertNewSurfaceAt 后立刻写属性会错乱，优先用 edit_surface。
4
extension 槽位全废时别改代码那是 .NET Remoting 注册状态烂了，重启电脑恢复；重启 Zemax 无效。
5
set_wavelengths 会重置操作数波长引用AXCL/LACL 的 (1,3) 会变 (1,1)，改完必须复查。
